# Lernspiele

Kleine Lernspiele für Deutsch (Klasse 7), erstellt mit Claude. Jedes Spiel ist eine einzelne HTML-Seite.

- `teil1.html`: Blockdorf in Gefahr (denn/weil, damit/sodass, Temporalsätze)
- `teil2.html`: Die große Baustelle (adverbiale Bestimmungen umformen, Satzglieder, verkleidete Konjunktionen)

Anmeldung mit Spielername und PIN. Am Ende wird das Ergebnis an einen privaten Webhook geschickt. Ohne Verbindung lässt es sich kopieren.
